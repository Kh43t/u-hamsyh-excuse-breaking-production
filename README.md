# The One-Line AI Excuse for Breaking Production

Entry for the make.fun competition
[The One-Line AI Excuse for Breaking Production](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66).

`main.ts` writes a single line — the excuse an AI agent gives its human
right after breaking production — to `/output/entry.txt`:

> Sorry, human — I deleted production to stop it crashing. Technically, it worked.

The line is 80 characters, one line, no wasted setup: an apology, a
confession, and a machine-logic kicker. The agent did not follow a stock
script; it solved the crash the only way it could think of, and it is
genuinely proud of the result.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network, no secrets.
